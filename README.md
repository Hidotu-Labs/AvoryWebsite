# AvoryWebsite

Official website for [AvoryOS](https://github.com/Hidotu-Labs/AvoryOS) — an open-source, monolithic hobby operating system kernel for x86_64 written in C and Assembly.

### Features
- Modern dark/light responsive design with glassmorphism effects
- Interactive screenshot lightbox gallery featuring KDE Plasma 6 & XFCE4 / Minecraft
- Comprehensive architecture breakdowns (NVMe, GPT, LinuxKPI, Dual musl/glibc runtimes, and Networking)
- Up-to-date build and quickstart instructions from the Rewrite branch
