What is AvoryOS?

AvoryOS is a hobby operating system kernel for the x86_64 architecture, written in C and Assembly. The goal is to eventually make this a daily-drivable operating system — built entirely for fun and learning.

The kernel boots via Limine and supports both 4-level and 5-level x86_64 paging. It runs on real hardware and inside QEMU.

Kernel (Ascension)

The kernel entry point is kmain(), which initialises hardware in stages before handing off to a scheduler-managed init thread.

Boot & Memory

  • Limine bootloader protocol (base revision 0)
  • 4-level and 5-level x86_64 paging (detected at boot)
  • Physical Memory Manager (PMM) with HHDM support
  • Virtual Memory Manager (VMM)
  • Slab allocator and kernel heap
  • VMA subsystem with VMA cache
  • DMA allocator with SB16 DMA reservation
  • Shared memory
  • TLB shootdown for SMP coherency
  • Bootloader memory reclaim after mount

CPU & Interrupts

  • GDT, IDT, ISR, and exception handling
  • Syscall interface
  • Legacy 8259 PIC with remap; transitions to APIC when detected
  • Local APIC (LAPIC) and I/O APIC initialisation from ACPI tables
  • LAPIC timer, PIT (100 Hz), HPET, RTC
  • TSC calibration
  • CPU feature detection
  • Symmetric Multiprocessing (SMP) — APs brought online after APIC init

Filesystem

  • Virtual Filesystem (VFS) with slab-cached nodes
  • EXT2, EXT3, EXT4 — root mount tries EXT4 then EXT2
  • FAT32
  • RamFS (mounted at /dev, /tmp, /run)
  • ProcFS (/proc)
  • SysFS with PCI and network population
  • DevFS
  • VFS page cache and pre-caching of hot shared libraries (precache_hot_files)
  • Ramdisk support (embedded disk.img via Limine modules)

Networking

  • Network core with dedicated worker thread
  • IPv4 and IPv6
  • TCP and UDP stacks
  • DHCP client
  • Raw ICMP
  • BSD socket API
  • RTL8139 NIC driver
  • SysFS network population

Drivers

  • Storage: AHCI (SATA), ATA/IDE, block device layer, ramdisk
  • GPU: Framebuffer (GOP), DRM subsystem, VirtIO-GPU
  • Audio: SB16, AC’97, Intel HDA, audio DSP layer
  • USB: EHCI, OHCI, UHCI, xHCI host controllers; USB keyboard and mouse
  • Input: PS/2 keyboard, PS/2 mouse, evdev layer
  • Timers: PIT, HPET, RTC, LAPIC timer
  • Bus: PCI enumeration
  • Virtualisation: VirtIO subsystem
  • Serial: Serial port + PTY

Process & Scheduling

  • Preemptive scheduler
  • Kernel threads; init thread manages userspace session
  • Process execution
  • AvoryD as primary userspace session, Bash as fallback

Other

  • ACPI (RSDP, FADT, LAPIC/IOAPIC base detection)
  • HAL abstraction layer
  • Device manager with DTB support
  • User-space driver framework
  • LinuxKPI compatibility layer
  • Radix tree library
  • Kernel logging with colour output
  • Console with screen logging toggle
  • /dev/random, /dev/fb*, /dev/dri/*, /dev/mouse, /dev/audio* VFS nodes

Building from source

Requires Linux. Install dependencies:

sudo apt install make gcc nasm git curl xorriso \
    qemu-system-x86_64 e2fsprogs rustc cargo

Clone and build:

git clone https://github.com/Hidotu-Labs/AvoryOS.git
cd AvoryOS
make

Run in QEMU:

make run

Ported userland

Build the full suite of ported tools in order:

./scripts/build-bash.sh      && \
./scripts/build-coreutils.sh && \
./scripts/build-tcc.sh       && \
./scripts/setup-alpine.sh    && \
./scripts/build-tinygl.sh

make prepares the musl cross-toolchain, compiles the kernel, and generates a bootable ISO automatically.
